# 多模态情感流研究：截至 2026 年 10 月 12 日的方案总整理

本整理将前期原型、端到端模型、任务效用控制、教师与校准、正式比较、五折计划，以及尚未执行的建议放在同一条研究线上。依据是已保存的实验报告、源码、指标原件与接续记录；历史文件中的“正在运行”“尚未完成”按后来的真实完成证据更新。没有重新训练、推理、读取未评分 OUTER 标签或重算实验分数。

**当前用户安排：集中整理现有方案，暂停新的训练准备和派发。** 此安排不等于终止其他健康进程，也不改变已经冻结的实验结果。

## 1. 目前可以确认的研究结论

1. **早期有正向结果，必须保留。** 在早期官方划分的五随机种子比较中，V6 single 的 TEST MAE 为 **0.63436±0.00576**，当时 CaReFlow 为 **0.65684±0.02222**；V6 single 的五项平均点值均更好。相对同条件 V6 plain，MAE 平均低 0.00665，只有 3/5 个种子更低。这是有价值的探索结果，尚未证明稳定显著优势，亦不能把跨版本差异全部归于流结构。[E05]
2. **近期重新对齐的官方流程没有实现五项全面超过。** 新 CaReFlow 参考 TEST MAE 为 **0.619535**。固定完整流 F 为 0.643700，官方 Huber 消息版为 0.650616，MSE-only 为 0.652712，极性×强度为 0.638176，匹配辅助回归为 0.635505。极性×强度只在 Acc2/F1 点值上高于这份 CaReFlow；辅助回归五项均落后。[E26] [E27] [E28] [E29] [E30]
3. **还没有识别出真实数据上唯一、可验证的“共享／互补／干扰”语义分解。** 几何重叠、可逆性、可重建性、交换不变、任务梯度非零，分别只能证明对应性质。多个合成反例已经说明，它们不能自动升级成共享语义或信息论 PID。
4. **控制器优化自己的代理目标，并不保证真实任务收益。** OOF 教师的预测本身不错，但直接驱动旧消息修改，TRAIN MSE 从 0.016128 升至约 0.0768–0.0789。必须分别检验方向、真实位移幅度、接受信号与终端非线性输出。[E17] [E18] [E19] [E20]
5. **完整五方法、五外折比较仍未完成。** 预定 25 组最终外折结果、实际 35 个训练阶段；目前正式保存 **1/25 组未评分 OUTER 预测，0/25 组五项评分**。完成的是 CaReFlow fold0；fold1 只有 native3 资格实验，未完成正式 100 轮。[E34] [E35]

“已有积极点值”“没有稳定显著证据”“近期正式比较失败”“完整五折尚未完成”可以同时成立，不互相替代。

## 4. 早期原型：从预分支到流内关系

### S01–S05：V1到V4

**V1** 把每模态分为共享24维、特有24维、其余16维，只让共享支经过两步速度场对齐。三种子 TEST MAE：文本0.9935、拼接0.9848、三分支无流0.9933、共享流0.9830。其余支标签线性探针R²约0.37，和共享支相当，分支命名未得到语义证据。追加去相关后R²降至−0.1147，但MAE升至1.0092；这是看过首轮测试后的探索。[E01]

**V2** 保留时序、冻结编码器，用可逆坐标变换分配共享／补充／残余。测试MAE：时序拼接0.9716、冻结新头0.9852、可逆无流0.9887、可逆加传输0.9949。回环误差约1.2×10⁻⁶，证明数值可逆；不证明语义可识别。共享传输的配对距离在三个种子中只有两个下降。[E02]

**V3** 使用高斯任务方差参与融合、拉近和循环反馈。一次分解／普通循环／不确定性循环MAE为0.9800／0.9876／0.9817。不确定性原始90%区间覆盖仅27.5%；校准后89.3%，但宽度约4.019。校准尺度有效不等于路由可靠；音视频扰动也未稳定提高预测方差。[E03]

**V4** 让完整表示先进入条件耦合流，再读三路共有G、两两共有P与单路特有U。均匀／动态重叠／中段反馈／完整循环MAE为0.9787／0.9844／0.9824／0.9775。完整循环相对中段反馈三个种子都改善，但同一完整循环检查点第一次完整输出0.9771，最终0.9775，额外推理循环没有平均收益。条件流层可逆不等于整个反馈系统可逆；七类几何归属不是PID。[E04]

这些原型使用 MMSA 的1284/229/686版本和较弱固定表示，不能把其约0.98失败扩展成官方CaReFlow或后期端到端方法失败。

### S11–S13：几何关系与来源身份

V7先让完整模态进入联合速度场，再测局部响应。修复了把不同接收流当同一坐标、误判共有的问题。任务保护控制满足局部一阶条件 `gᵀc=0`；有限非线性步仍有预测漂移。后来的24个DEV pilot已完成，不能沿用早期README的“未训练”；guarded/unguarded没有给主选模指标带来清楚收益，部分配置控制分支未真正启用。[E05] [E06]

V8几何反例进一步发现，共同隐藏层可使三个模态Jacobian具有同一输出范围，即使没有共同生成因子。多视图保护能在植入真值的合成例子中修补单一融合头盲点，但“后流音频块”可能携带文本来源。真实来源贡献要通过输入可用性贯穿整条流的路径验证；这份保护原型没有独立正式真实数据成绩。[E07]

另一组已经完成的七路线实验使用T/A/V/TA/TV/AV/TAV监督，包含完整路线单独监督和训练AV打乱对照。四组五种子TEST MAE依次为：七路线自然0.65854、完整路线自然0.64622、七路线打乱0.66119、完整路线打乱0.64000。没有一致的自然配对收益，不能把路线存在或分数差叫共享识别成功。[E05]

## 6. V9离线任务反馈、交换与基线校准

### S14–S16：由几何关系转向任务作用

四步小流在第二步读取任务均值／任务增量，再反馈后两步；推理前向不接收标签。合成24模型中，任务增量相对普通均值没有一致优势。真实固定池化原型先经历随机投影瓶颈（DEV MAE约1.29–1.30），再发生TRAIN常量通道除以极小尺度导致DEV MAE约13–14的数值失败。失败原件保留；后续只按TRAIN确定活跃通道、clip8等稳定处理。[E08]

稳定版none／均值／增量／区间约束DEV MAE约0.9152／0.9163／0.9112／0.9166；均值蒸馏版约0.9252／0.9252／0.9021／0.8990，但主要batch-MSE未一致改善。模型只有12维状态、固定池化输入和小优化器配置，不能代表端到端官方方法。

局部交换用正交投影P，`zA'=zA+αP(zV−zA)`、`zV'=zV−αP(zV−zA)`，α=.25让投影内差异减半。加InfoNCE和回环约束的合成／真实小实验已经完成；投影秩比例不是情感证据对齐比例，对比学习也可能编码共同噪声。[E09]

预测等价交换搜索另外要求：样本内双向单侧替换近似不变、跨样本替换有非平凡任务响应、两来源响应一致。实际两个投影候选只找到弱响应方向，未过预定门槛，未安装。完全等价只保持冻结预测器指标，不能直接提高其准确率。[E10]

### S17–S18：正则化、停止规则与校准迁移

无交换小模型完成了L2/dropout组合、多个TRAIN视频留出和固定4/8轮预算比较。内部选择曾偏向L2+dropout，重训后DEV却未稳定改善；固定预算下也显示停止点与正则化交互，不能把差异都归于一个loss。[E11]

独立视频角色fit/selection/calfit/calsel/audit的校准实验中，plain选定策略审计视频MSE差−0.002461，但MAE反而增加；L2drop策略MSE差+0.019156、MAE差+0.026148。校准选择集上的改进不会自动迁移到另一组视频；这条小原型扩展没有提供稳定部署方案。[E12]

## 8. 向量梯度、Jacobian与有限风险

### S23–S25：三类向量控制均未胜固定对照

| 实验 | 固定 / 标量 / 向量 DEV MAE | 实际判断 |
|---|---|---|
| 连续梯度向量 | .598450 / .598548 / .599209 | 向量无改进；软约束不等于精确风险半空间 |
| Jacobian约束 | .598444 / .598736 / .598960 | 梯度分解恒等式通过；方向与未知真实残差准确性不同 |
| 有限风险 A/B/C2 | .598442 / .598624 / .599325 | 代理大多改善但真实下降约半数，向量无胜出 |

有限预测变化δ相对锚预测p0的观测平方损失差严格为：

`ΔL = 2(p0−y)δ + δ²`。

丢掉δ²会漏掉大幅修改造成的损害。Jacobian投影与梯度cosine接近±1，可能只来自标量读出的秩一结构，不代表模型预测了正确残差符号。

原向量C在第11轮发生单有效token中心余弦零范数二阶数值失败；C2采用单token解析零分支后完成100轮。C2成功不能回填原C为成功。固定参考、骨干、流与解码器冻结，只训练供体和头520506参数；其旧参考已使用全TRAIN与DEV选择，因此不具有完整管线OOF资格。[E43] [E44] [E45]

### S26：Oracle的积极证据及其边界

固定C2模型、TRAIN1281：原消息MSE0.016128；学习残差三步0.015268（−5.33%）；真实标签Oracle三步0.005627（−65.11%）。这说明已拟合参考的消息有可纠错空间。学习控制只取得所观察有限Oracle增益的约8.19%。Oracle使用真标签，不可部署，也不是全局上界，更不能证明DEV泛化存在同样空间。[E17]

### S30–S31：严格恒等式与未知误差预算

相对原消息pF，令r=y−pF、δ=pZ−pF：观测风险差为δ²−2rδ。用残差估计rhat得到代理。若有真实条件均值误差上界ε，才能把代理加 `2ε|δ|` 构造成相应风险上界；目前没有获得这样的逐样本覆盖资格。OOF标签误差、模型分歧和任务方差都不能直接冒充它。[E21]

首步GPU几何核验进一步确认：同一标量终端和同一锚点，旧目标与教师目标梯度只有同／反向；1281行中同向666、反向615。正λ目标收缩后再把梯度单位化，λ会被抵消。要控制实际修改量，应明确消息步长与半径，而不是只改目标名称。[E22]

### S32–S34：真实有限候选与CAL

CAL418行/18视频按视频等权拟合 `λ=clip(C/B,0,1)`，三折λ为 **0 / .012728 / .062491**。经验输出cap来自旧移动分位数，不是真实风险保证；λ=0折严格回退。[E23]

真实消息池为F＋旧／教师／反向旧三个方向各四个半径，共13候选；相同预算比较旧+教师与旧+反向旧。EVAL863上F MSE0.014975、旧原生0.014087、CAL旧+教师0.015010，未支持继续这条扩展。[E24]

随后只做原生末端位移半径的CAL零标签机制预检：合法唯一候选平均数从约1.83升到8.89；非F覆盖从约96/418升至418/418。它纠正了网格覆盖问题，**没有新EVAL收益评分**，不能据覆盖改善宣布方法有效。[E25]

| 方案／建议 | 已有基础 | 缺失项／当前处置 |
|---|---|---|
| S52 非最终epoch复合恢复 | v2分支、审核函数34项、driver51项、10文件依赖capsule惰性探针 | 真实原件冻结审核plan、CPU审核及CPU/CUDA连续对照未过；仅单次fresh-origin设计，不支持恢复链 |
| S53 同教师冻结小头 vs 全量微调 | 旧约.598与新全量训练差异已梳理 | 未有同合法教师、同初态、同订单预算的匹配两臂；不可拿现有40轮充一臂 |
| S54 误差预算／置信度接受 | 风险恒等式、经验接受率诊断 | 真实条件均值误差覆盖未知；不把分歧大叫置信度高 |

| 更多半径／margin／输出门扫描 | 旧EVAL和TEST已访问 | 停止在已读集合上继续扫参数救分 |
