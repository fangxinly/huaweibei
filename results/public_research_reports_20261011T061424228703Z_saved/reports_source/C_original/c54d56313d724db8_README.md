# 固定官方划分的五随机种子重复实验

本目录保存队列程序和同步回来的监管记录。训练在已授权的远端服务器执行。

## 已确认协议

- MOSI作者划分：训练1281、验证229、测试685。
- 随机种子：128、0、1、2、3；每次100个epoch。
- 验证选择指标：作者定义的验证批次MSE非加权平均，batch128。
- 全部100轮完成并冻结选择记录后，评估测试集一次。
- seed128复用已经完成且核验的8组结果，其余新增32次。
- 不改作者实现、V5/V6训练源码、数据处理、优化器或损失权重。
- 最终报告5种子的均值及样本标准差（ddof=1），并计算同种子的成对差值。

## 执行顺序

官方CaReFlow四个新种子 → 原始plain → text_only → V5 single → V5 cycle → V6 plain → V6 single → V6 cycle。

GPU为单张Tesla P4，串行运行。全部任务的脚本及预训练资源由manifest锁定哈希。

## 文件和监管

远端根目录：`/data/coding/selective_flow/strong_baselines/repeat5_experiments`。

- `manifest.json`：固定协议、冻结资源哈希、seed128引用和32个作业。
- `status.json`：队列及子进程、当前epoch、GPU/空间和需处理的问题。
- `queue.log`：启动、完成、验证和失败事件。
- `runs/<模型>_seed<种子>/attemptNN`：独立训练输出，避免覆盖旧实验。
- `summary.json`、`结果汇总.md`：已核验结果的累计汇总；不足5种子的行明确标记为进度。

队列每15秒更新状态，每分钟读取GPU和空间；聊天监管每10分钟检查并处理。没有实质变化时不重复通知。

完成条件包括100条连续history、验证选模一致、checkpoint/protocol/源码哈希一致、预测和指标核验通过、子进程退出0及完成标记。

冻结runner没有完整断点续训功能。可恢复失败至多按相同设置在新attempt重跑一次；保留失败输出。不可恢复失败或重复失败停止队列并记录需处理原因，不删除文件，不自动杀死其他进程。

## 操作边界

只处理本研究项目和已授权SSH训练。不删除原文件、不打开网页、不修改用户电脑设置、不委派其他AI代理。

本地聊天监管依赖桌面应用运行。远端串行队列通过后台进程运行，SSH断开后仍可继续；服务器退出或资源耗尽时仍需恢复处理。
