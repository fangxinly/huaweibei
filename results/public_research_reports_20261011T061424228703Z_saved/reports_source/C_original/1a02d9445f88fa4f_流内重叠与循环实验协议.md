# 第四轮：完整模态流中的七类重叠关系与循环反馈

实现入口：`../train_v4_overlap.py`。这是第三轮不确定性路由没有稳定收益后的结构实验；不再将未经校准的方差作为共有／特有的判定依据。第三轮代码和结果保留。

## 1. 全模态流先表示，再读取关系

每路沿用对应种子的冻结时序编码器与训练集归一化，得到64维h_m。每个模态进入独立六层条件affine coupling流，整路64维同时变换。没有共享／私有预分支，也没有固定的24／24／16语义切片。

前3层得到中间状态z_m^mid，后3层得到末端状态z_m^end。两处都可以读取跨模态重叠；循环版本把关系用于中段流条件和下一次全流条件。

这里使用离散耦合流，未实现连续时间rectified flow。流在保存对应条件的情况下可检查解析逆；关系读取、软匹配与分组并不具有完整可逆性。

## 2. 共同参照下寻找局部相似性

将每路64维流状态重排成8×8的局部特征。8个共同可学习查询，每个查询维度8，对三模态使用同一组参照。

查询与各模态局部特征的归一化余弦构成8×8匹配分数，温度0.3，经过12轮行／列log-normalization形成近似双随机软匹配。最终再归一化行，避免全部查询都选中同一个局部特征。匹配输出仍为每路8×8，但对应槽位具有共同查询参照。

查询是几何参照，并没有预先标注情感概念。8维局部块也不天然对应词、声音事件或面部动作。因此这一步实现的是可学习的几何配准，不能直接称为真实语义匹配。

同一参照槽位，计算三对跨模态余弦相似度，并使用：

    q_mn = sigmoid((cosine_mn - 0.3) / 0.2)

q是软匹配评分，不是校准的共有概率，也不是信息论互信息。

## 3. 七类信息与归属权重

输出：G、P_TA、P_TV、P_AV、U_T、U_A、U_V。每组保留8槽×8维＝64维，最后拼接448维供情感预测。

对于模态m及另外两路n、p，令a=q_mn、b=q_mp、d=q_np，则该模态每个槽位的四种局部归属为：

    三路共有：g = a*b*d
    与n两路共有：p_n = a*(1-b) + 0.5*a*b*(1-d)
    与p两路共有：p_p = b*(1-a) + 0.5*a*b*(1-d)
    单路特有：u = (1-a)*(1-b)

这四项非负且和为1。只有三条关系均成立时才进入全局共有；某条关系强且第三路不匹配时进入两路共有。若两条关系强、第三条弱，歧义质量分配给两种配对，避免丢弃这种可能的情感冲突情形。

使用归属权重平方根加权相应槽位：G对三路加权表示取平均；每个P对其两路加权表示取平均；每个U保留本路加权表示。最终头为448→128→64→1，GELU、Dropout0.2。

这是软路由，每个局部特征可以按权重参与多类。不能把G和P解释为严格集合交集，也不能认定U只含该模态的因果独有信息；相似性、重复信息、互补协同是不同概念。

## 4. 流中段反馈与全流循环

每个模态的反馈输入包括：本路流状态64维、四类局部归属32维、与另外两路的关系评分16维，共112维。独立MLP112→64→32产生条件更新：

    c_new = 0.5*c_old + 0.5*tanh(B_m(SG(local_state, membership, relation)))

反馈输入停止梯度，B和后续条件流仍由情感损失学习。不直接拼接其他模态的内容向量；关系评分本身依然依赖其他模态，故不能宣称完全避免跨模态信息泄漏。反馈不用真实标签。

中段反馈：前3层流→读取关系→更新条件→后3层流→再次读取关系。

全流循环：末端关系再次更新条件，以原始h_m重新进入同一组六层流；内部仍在第3层后更新条件。同一模态各循环复用全部参数。

两次完整前向合计每模态12次耦合层调用。训练与推理运行相同路径。逆检查使用最后一次完整前向保存的初始和中段条件分别反解两段流；不证明整个带反馈系统全局可逆。

## 5. 四个对照

| 模型 | 关系分配 | 中段条件更新 | 全流次数 |
| --- | --- | --- | --- |
| uniform_single | 每个本地角色固定1/4；仍做共同参照匹配 | 无 | 1 |
| overlap_single | 动态匹配归属 | 无 | 1 |
| overlap_mid_feedback | 动态匹配归属 | 有 | 1 |
| overlap_cycle | 动态匹配归属 | 有 | 2 |

四个模型均构造相同模块、拥有484897个参数，配对初始化一致。未启用的反馈模块仍计入参数总量，因此不把相同总参数数目冒称为相同有效容量。中段预测使用同一预测头作辅助监督，所有对照都计算中段关系。

本轮主要比较overlap_single与uniform_single、overlap_mid_feedback与overlap_single、overlap_cycle与overlap_mid_feedback。跨第三轮比较因预测头、目标和结构改变，只作历史参照，不作严格消融结论。

## 6. 固定目标与训练

每个关系读取位置：

    情感MSE
    + 0.02三路共有视图的跨模态对比损失
    + 0.01三对两路共有视图的对比损失
    + 0.0005局部归属熵
    + 0.0001全流状态能量

对比损失温度0.2，同一样本为正对、其他样本为负对，以停止梯度的相应归属质量加权。情感相近样本可能是假负对；需要作为方法限制保留。小熵项鼓励明确归属，但不人为要求每类占固定比例。

单次完整流目标=(末端损失+0.1中段损失)/1.1；两次循环目标=(第二次目标+0.25第一次目标)/1.25。

AdamW学习率5e-4、weight decay1e-3、batch size64、梯度裁剪5。种子0、1、2；最多60轮，验证MAE连续12轮不改善停止，以验证MAE选检查点。以上阈值、温度和目标权重均在本轮启动前固定。

## 7. 验证是否真的找到了有用关系

- 预测：MAE、Acc2、相关；另报告三模态均非空子集。
- 循环：同一个模型第一／第二次完整流的MAE，中段MAE、条件范数。
- 路由：每路四种局部归属的平均质量，是否所有特征挤到同一类。
- 分组：训练拟合并用验证集选正则的G、G+P、全部、P单独、U单独线性探针。
- 使用情况：推理时分别将G、三种P、三种U置零。置零是分布外诊断，不等同于重新训练去掉某组的模型。
- 对应关系：打乱某一路样本对应，检查涉及该模态的匹配余弦、全局质量与预测是否变化。这验证样本关联敏感性，不能证明抽取了严格共有信息。
- 实现检查：局部归属和为1、典型三路／两路／单路边界、匹配对局部特征顺序的稳定性、反馈梯度、保存条件后的逆误差。

如果动态匹配没有优于均匀路由，或全流循环没有优于中段反馈，应如实判断相应机制未提供收益。即使MAE改善，也需要上述诊断支持关系分配的解释。

[Tri-Subspaces Disentanglement for Multimodal Sentiment Analysis (TSD)](https://arxiv.org/abs/2602.19585)已研究全局共有、两路共有和模态特有层级。本实验不是TSD复现；拟检验的是完整流状态的软配准、关系读取及其对后续流的反馈。尚未完成足以证明方法新颖性的专门检索。
