# 交换依赖与结构收益的区别

## 本轮新补齐的同样本对照

针对上一轮提出的解释，补齐了同一个合成留出集合上的训练×推理开关对照。两个场景、三个种子，均使用 seed91604 的同一批 1000 行；六个最近的无交换学生新增冻结 CPU 推理，局部交换学生的开／关预测复用已有保存数组。没有重新训练、访问 MOSI/test、加载旧 84 大权重或重跑原有诊断。

六个局部交换学生关闭交换都变差：开减关的平均 MSE 差为 −.002842、−.003565。但与独立训练的无交换学生相比，局部交换正常开启的成对差仅为 −.000137±.001094、+.002226±.003125。共享场景近似持平，冲突协同场景平均更差；每场景只有一个种子优于独立无交换学生。

这支持“当前模型已经依赖训练时交换”这一解释，尚未支持稳定的结构收益。无交换学生的 basis 在训练中未被使用，开启交换时是未训练 basis 的扰动；局部交换学生的 basis 经过训练。因此这个交互包含 basis 学习差异，不能单凭交互量归因为共享子空间或来源因果。每个模型都沿用原独立 validation800 最小 MSE 选出的 checkpoint；seed91604 此前用于探索分析，属于已查看的探索性留出数据。

## 为什么关闭有效模块，不等于这个模块有优势

记训练得到的参数为 θₐ。冻结消融比较的是 R(θₐ,0) 与 R(θₐ,a)。独立无交换训练比较的是 R(θ₀,0) 与 R(θₐ,a)。这是不同的问题：前者测训练后依赖，后者测完整训练方法相对于对照的收益。

当前对称投影交换为：

a′ = a + α(v−a)P，v′ = v − α(v−a)P，P²=P。

它保持 a+v；投影中的差异变为 (1−2α)(a−v)P，投影外差异保留。α=.25 时，差异只是乘以 .5，整个交换映射可逆。后续足够灵活的预测器可以补偿这个坐标变换。可逆交换没有自动删除信息，也没有自动识别共享证据；收益可能来自优化、条件数或正则效应，需要匹配对照检验。实际有限宽度的非线性 flow 不能因此被宣称训练轨迹或表达能力完全等价。

α=.5 时，投影差异被消除，才会发生不可逆的信息损失；若其中含互补证据，任务可能受损。把收缩强度叫作“半对齐”会混淆几何操作与实际证据一致度。

## 新数学反例实际执行

`check_exchange_reparameterization_v1.py` 使用 1000 个已知线性构造样本、d12/rank3/α.25，分别构造原坐标的准确预测器与补偿交换的准确预测器。两者正常配置 MSE 为 0 和 2.10×10⁻³⁰；关闭补偿预测器的交换，MSE 却上升到 5.006888。交换逆矩阵残差 6.66×10⁻¹⁶；α=.5 的反对称投影方向响应约 6.09×10⁻¹⁷，α=.25 响应 .5，全部断言通过。

该构造展示了“显著消融伤害但没有结构收益”的可能性，不能代替真实 flow 的实验证明。

## 对下一轮设计的具体影响

1. 继续保留独立训练的无交换基线，同时报告冻结开关消融。
2. 先解决 MOSI 小原型过拟合；不能用弱预测器忽略的方向来判断真实共享证据。
3. 若比较样本条件交换，应同时保留固定强度与训练时包含 α=0 的控制，检查候选收益是否仅来自对固定变换的适应。
4. 共享候选仍需同实例单侧替换近似不变、跨实例任务响应一致且非零，以及样本外效用。对称交换、几何收缩和可逆性分别记录。
