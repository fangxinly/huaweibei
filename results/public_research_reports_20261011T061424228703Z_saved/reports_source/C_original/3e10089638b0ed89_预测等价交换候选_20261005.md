# 从预测等价交换寻找共享候选

人类最新提议：先找不影响结果的局部交换，再考虑把它作为共享部分使用。已按此方向推导并实际执行一个冻结模型的无标签候选搜索。数学反例、正负例与 MOSI 结果均保留。

## 定义与可识别性边界

设第二步后的来源状态为 zT,zA,zV，F 为剩余两步流加任务解码器。交换算子 T 保持预测，当 F(Tz)=F(z)。这里是对已训练模型和具体数据分布的预测等价；不要求额外的关系教师或关系标签。

需要区分三个反例/正例：

1. **无关或被忽略的方向。** 模型根本不使用某个坐标，交换、删除、跨样本替换该坐标都不改变输出。单看交换等价会把它错误叫作共享任务证据。
2. **成对抵消。** F(a,v)=a+v 时，完整互换 a/v 使输出严格不变，即使 a/v 提供互补数值。单向复制 a←v 通常改变输出。因此增加双向单侧替换检查。
3. **真正的重复任务因子正例。** 两来源均含同一个随样本变化的 s，F 同时使用它们。样本内复制不改变结果；跨样本单侧替换 s 会改变结果，两来源的替换响应一致。

本地已实际核验：互补求和的成对交换预测变化0，单向复制变化 MSE1.916274；重复因子样本内复制变化0、跨样本响应 MSE.493371；被忽略坐标的两种响应均0。另1000次平方误差变化界检查全部通过。初版 JSON 的报告阶段复用 base 变量，两个求和字段错误，原始断言正确；错误文件保留，新增 `check_equivalence_counterexamples_v2.py` 与 v2报告正确运行，不覆盖历史。

**完全预测等价会使这个冻结预测器的所有预测指标保持，不会直接改善准确率。** 潜在收益应另行检验：减少重复计算、促进后续训练，或让近似交换能改善真实任务风险。

近似等价 |Δp|≤ε 时：

    Δloss = 2(p−y)Δp + (Δp)²
    |Δloss| ≤ 2|p−y|ε + ε²

若 p,y∈[−3,3]，ε=.02 的最坏平方误差变化界仍有 .2404。因此“预测只动一点”不是强风险安全保证。本轮使用 RMS 容差作候选条件，并另外报告逐样本覆盖；不能说所有样本都满足 .02，也不能说全局等价。

## 候选搜索实现

使用最新小原型的 **none** 模式第3轮最佳冻结权重，SHA `3e69a8d3e3cf0245da289ab6ebed56dd6ac3fc198d025793a28014290c0c2884`。未加载84旧端到端权重。缓存仍为未受 MOSI 监督的固定预训练表示，SHA `1079f9c9c65e654840be8d6a7702419118220ef4e0efd14db5a1ce53f73a4c42`。无 test、无重新编码、无学生更新。剩余流的手动重建预测与保存 dev预测最大差0，学生前后SHA相同。

任务学生以前受官方 train 标签监督；本轮 **搜索和选择候选不读取标签作为目标**。这不意味着整套任务预测模型是无监督训练的。也不把本轮 train 状态当作学生未见标签的独立任务风险校准。

学习一个 rank3/d12 的正交 Q，P=QQᵀ，在第二步后分别操作：

- A单侧替换：zA←zA+P(zV−zA)，V保持。
- V单侧替换：zV←zV+P(zA−zV)，A保持。
- 成对交换：两侧同时替换投影内坐标。
- 跨样本替换：A或V的投影坐标来自另一 train 样本，测量任务预测响应。

两组同初始化、同采样的300步 Adam .01 搜索，只有 Q 更新：

- 等价优先：最小化两次单侧替换的预测变化平方均值。
- 等价+响应约束：增加跨样本A/V响应差及任务响应能量不足的软惩罚。

train前641行拟合投影，后640行按无标签响应损失选投影。候选验收门槛在 dev前固定：单侧替换 RMS≤.02、跨样本替换 RMS≥全部A/V坐标替换 RMS的25%、两来源响应余弦≥.8。软惩罚不保证约束满足；未满足时诚实拒绝。

固定跨样本 donor 是当前无标签样本的循环下一行，不根据标签选择。不声称这个替换是分布内干预或因果识别。

## 下一项研究

保留人类的等价交换方向。先提高同输入无交换模型的泛化，或者恢复充分的序列表示和端到端适配；现有12维冻结池化原型明显过拟合。然后重新测试双向单侧可替换性、非平凡任务响应、多种有限交换幅度和样本外稳定性。

如果出现通过无标签判据的候选，再设计同容量新训练对照，检验使用它是否能保留互补因子、降低错误交换和改善主任务。当前没有候选通过，因此不直接装成共享模块。不把全train监督学生的同train误差声称独立风险校准。
