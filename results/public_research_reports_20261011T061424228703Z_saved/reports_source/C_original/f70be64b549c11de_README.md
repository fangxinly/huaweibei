# V8 研究修订：从响应范围转向任务功能

## 状态

本目录保存两项独立 CPU 诊断与一个控制算子原型；尚未实现或训练完整 V8 真实数据模型。旧五随机种子实验和已排队的 V7 预测对照均保持其冻结协议。

## 新发现：共同隐藏层会制造共同响应范围

当前联合速度场使用同一个隐藏层输出完整三流的速度。在给定时间、固定反馈 context 的局部测量中，模态 m 的池化雅可比可以写为：

`J_m(z) = K(z) * W_in,m`

K 是三个模态共同使用的输出映射；W_in,m 是第一层连接模态 m 的权重。当这三个输入矩阵都满行秩时，三个雅可比的输出范围都是 range(K)，即使输入没有植入共同生成因子。

诊断保留当前 JointVelocity 结构，dimension=hidden=16，在种子128、0、1、2、3中验证：

- 三个完整雅可比均秩16；三个输出子空间的差异范数约 1.9e-14 至 1.15e-12。
- 4个或8个探针时，没有方向被可靠判为多个模态共同驱动。
- 16个探针时，16个候选方向全部被判为三者共同驱动。
- 同一组网络权重和输入没有改变；变化来自探针覆盖与模型结构。

因此，增加探针或放宽阈值不能把动力学范围变成共享情感分解。V7 仍可以检验联合速度场、反馈和几何控制的预测作用，但不能用其响应范围结果证明信息类别已被识别。

有限差分还会产生微小离开精确雅可比范围的分量。报告中的 measured_rank 有时大于16，这是中心差分误差与机器精度秩阈值共同作用的诊断，不代表新增了强信号方向。分类只在主要16维候选空间中进行；后续应将有效响应秩与扰动尺度一起审计。

## 新候选：在流中保护多个任务视图

单一融合预测器可能过度依赖文本。只保护融合预测不变，仍可能抹去模型暂未利用的音频或视觉证据。因此，下一阶段考虑共同保护已经训练并验证可靠的单模态、双模态和完整模态预测视图。

完整三模态仍从一开始进入联合流。视图在流内进行观测，不在输入前预先命名共享/特有/噪声分支。信息关系使用任务功能来检验：能否替代另一模态提供同样有效的预测，是否提供额外预测贡献，以及是否属于多个可靠任务视图都不敏感的变化。

这些是任务相关的功能判据，尚不是已识别的信息论 PID，也不能把任意混合梯度的重叠直接当作共享语义。

### 控制原型

`multi_task_guard.py` 接受一个半正定控制算子 A，以及 K 个可靠任务预测的状态梯度组成的 G。它使用：

`c = -alpha*A*z - A*G^T*(G*A*G^T)^+*G*(-alpha*A*z)`

只求 K×K 矩阵的伪逆，不构造全序列的大矩阵。在固定 A 下，控制保持 `G*c=0`，即所有所选任务视图的一阶预测不变；控制的状态内积非正。真正的任务学习速度场仍可改变情感预测。

在已知真值的合成例子中，文本主导的融合约束允许音频情感坐标的控制方向变化率为0.13；步长0.25对应坐标变化0.0325。加入音频与视觉任务约束后，这三个已知情感坐标的控制方向变化降到约2.78e-17，同时以步长0.25更新后的已知干扰坐标范数由2.5593降至2.4953。重复约束、零控制算子和状态梯度检查通过。

这只说明多视图约束可以修补单一融合头的盲点，不证明真实数据上一定有益。未经训练或校准的辅助头可能保护错误方向，不能直接把它们接入正式方法。

## 下一步可证伪实验

1. 同样完整模态编码器与同样四步流；所有对照拥有相同视图预测头及辅助任务损失，避免把新增辅助监督的收益归于控制。
2. 比较无控制、单融合预测保护、多任务视图保护，控制强度与步数保持匹配。
3. 单/双/完整视图只使用训练样本训练，使用验证集检查预测可靠性与不确定性；流内干预视图需有对应训练，不能依赖未见过的遮挡输入。
4. 联合预测利用弱模态时，记录模态移除与等长度打乱的验证变化，确认额外证据确实被利用。
5. 检验非线性有限步长预测漂移、多视图梯度冲突、约束秩和实际控制范数；未启用或过度冻结时如实报告并修改假设。
6. 候选通过机制与验证集对照后再冻结，按官方划分进行五随机种子统计；不使用测试集选择结构或强度。

## V8C：流内观测来源的进一步修订

`versions/v8c_observation_audit/` 新增后流接收块观测的独立 CPU 合成反例与研究要求。即使后流音频块的预测在验证样本上可靠，它仍可能读取由文本传入的证据；在输出末端遮挡文本块不会消除这种传输。因此，多任务视图应明确区分接收位置和原始输入来源；评估原始单/双模态贡献时，应训练并验证输入可用性贯穿整条流的干预路径。

该检查使用独立生成的合成训练/验证样本，各4096条，五个种子；未用真实数据、测试集或 GPU。它没有完成 V8 真实模型、校准或正式训练，也没有改动排队 V7 的冻结方案。
