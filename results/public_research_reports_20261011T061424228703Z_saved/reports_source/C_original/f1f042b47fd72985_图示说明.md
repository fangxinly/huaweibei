# 两轮实际模型结构图

本文件说明 `train.py` 和 `train_v2.py` 已执行的模型。图中的 Shared、Private、Nuisance 是训练时赋予坐标的操作性名称，不能据此认定分解已具有严格的语义。两轮都使用 MOSI 预提取特征与连续情感标签，没有微调原始特征提取器。

图中蓝色表示共享候选信息，橙色表示私有／补充候选信息，紫色表示残余／噪声候选坐标，绿色表示冻结信息入口和可逆坐标变换。实线表示前向预测或阶段间信息传递，虚线表示辅助训练或诊断；`SG` 是停止梯度，`*` 是逐元素乘积。T、A、V 分别表示文本、语音、视觉。`Linear(in,out)` 给出输入与输出维数。

## 第一轮：统计汇聚后的非可逆三分支

![第一轮实际结构](v1_projection_shared_flow.png)

每段输入的文本、语音、视觉特征分别为 50×768、50×5、50×20。按照各模态有效帧掩码取均值和标准差并拼接，得到 1536、10、40 维向量；统计量由训练集确定，用于标准化并截断到 [-5,5]。该处理丢失序列顺序。

三路独立编码器将各自输入映射为 96 维：Linear → LayerNorm → GELU → Dropout(0.1)。随后每路的 Linear(96,64) 把向量投影到共享 24 维、私有 24 维、噪声候选 16 维。这一步降低维数，**不具有可逆性**。

共享分支分别经过速度场 MLP，结构为 25→64→24，隐藏激活为 Tanh；25 维来自共享状态的 24 维和时间 τ 的 1 维。采用两步 Euler 积分，步长 0.5。三路传输结果取平均，再用 24→32→1 的 GELU 预测头得到基础预测。

私有分支拼接三路原向量及三对逐元素乘积，合计 144 维，进入 144→64→1 的 GELU＋Dropout(0.2) 预测头。最终预测是基础预测加该输出。**此轮没有显式监督私有输出去拟合标签残差**，它只通过最终预测损失学习。

三类坐标合并后，经每模态 Linear(64,96) 重建编码特征，目标停止梯度。噪声候选还经过梯度反转层和独立 Linear(16,1) 标签回归头；反转强度为 0.1，回归损失权重为 0.02。补充的事后版本 `selective_flow_decor` 增加权重 5 的噪声坐标与标签相关系数平方惩罚。

速度匹配的目标是同一样本三路共享坐标的对称均值。该目标只用于训练速度场，**推理时速度场并没有接收其他模态作为额外条件输入**。无流对照 `factorized` 直接平均共享坐标，不使用速度场及速度匹配损失。

## 第二轮：先冻结时序入口，再做可逆坐标分配

![第二轮实际结构](v2_temporal_invertible_shared_flow.png)

第一阶段保留各模态有效帧的原始顺序，逐帧投影至 64 维，经双向 GRU（每方向隐藏维度 32），拼接末端状态并经过 LayerNorm 得到每路 64 维表示。三路表示拼接为 192 维，以 192→128→64→1 的预测头训练，附加权重 0.05 的三路单模态标签预测。验证集 MAE 选择检查点后，编码器冻结，并在 eval 模式下计算固定表示；第二阶段用训练集表示统计量做归一化。

第二阶段每个模态有一个独立的四层 affine coupling 坐标变换，64 维进、64 维出，随后划分成 24／24／16 维三组。耦合层使用交错二进制掩码；其内部 MLP 是 64→96→128，输出 64 维缩放参数和 64 维平移参数，缩放对数由 0.3×tanh 限制。最后一层线性权重和偏置置零，使坐标变换从恒等映射开始。

这个模块有解析逆变换，可以从全部三组坐标恢复输入的 64 维固定表示；**它不能恢复原始序列，也没有密度估计的似然目标**。第二轮不再训练额外的重建解码器，图中逆变换是数值正确性诊断。

共享坐标另经过与第一轮相同宽度的三路速度场，但改为四步 Euler 积分（步长 0.25），并增加近似反向积分回环损失。速度场输出层同样从零初始化。该传输与前面的可逆耦合层是**两个独立模块**：前者只处理共享坐标，后者重新组织全部三类坐标。Euler 离散传输没有解析可逆性的保证。

共享结果均值进入 24→64→1 的 GELU 基础头，该头也复用于每路共享向量的辅助标签预测。私有／补充分支仍使用 144 维拼接和交互输入，预测头改为 Dropout(0.15)，并明确添加 `MSE(delta, y-SG(y_base))` 的残差监督。

残余分支用批内标签相关惩罚替代首轮的梯度反转回归头。其权重在前五轮逐步增加；验证集从 0、0.5、2 中选出共同权重 2 供无流／有流对照使用。另有残余标准差下界、弱共享—补充相关和小幅潜变量能量约束。冻结编码器后，这些约束只能改变坐标变换及第二阶段模块，不能回传修改信息入口。

## 两轮对照

| 项目 | 第一轮 | 第二轮 |
| --- | --- | --- |
| 输入处理 | 均值＋标准差汇聚 | 保留有效帧顺序，双向 GRU |
| 学习入口 | 神经编码器与分支联合训练 | 先预训练编码器，再冻结 |
| 三分支划分 | Linear(96,64)，不可逆 | 四层 affine coupling，64→64，可逆 |
| 分支尺寸 | 每模态 24／24／16 | 每模态 24／24／16 |
| 共享速度场 | 25→64→24，2 步积分 | 25→64→24，4 步积分，增加近似循环约束 |
| 共享预测头 | 24→32→1 | 24→64→1，增加每路共享辅助预测 |
| 私有预测目标 | 最终预测共同优化 | 增加标签残差的显式监督 |
| 噪声／残余约束 | 弱 GRL；事后加去相关 | 去相关＋方差约束，编码器被冻结 |
| 信息恢复 | 学习 64→96 重建头 | 解析逆变换，只恢复固定 64 维表示 |

## 导出与复用

- `two_round_architectures.pdf`：两页矢量 PDF，第一轮与第二轮各一页。
- `v1_projection_shared_flow.svg`、`v2_temporal_invertible_shared_flow.svg`：可编辑矢量源图。
- 同名 `.png`：2440×1650 的图像预览。
- `draw_architectures.py`：绘图源码，仅生成图示，不修改或训练模型。需要 ReportLab 和兼容的 TrueType 字体。

图的版式与损失系数以本项目实际实现为准，展示的是探索性原型。低标签探针分数或可逆回环误差并不足以证明“共享、互补、噪声”已被准确识别。
