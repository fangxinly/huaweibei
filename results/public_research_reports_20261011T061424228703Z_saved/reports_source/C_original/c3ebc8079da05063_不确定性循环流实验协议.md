# 不确定性参与信息分配的循环条件流

本轮落实第三版结构提案并新增不确定性路由。训练入口：`../train_v3_uncertainty.py`。当前任务使用MOSI连续情感标签，因此使用异方差高斯回归，不使用离散类别的Dirichlet证据模型。

## 结构

保留第二轮的三组预训练时序编码器，各种子对应自己的固定编码器；使用其训练集统计量归一化每路64维表示。编码器不更新。每个模态的64维完整表示直接经过六层条件affine coupling流，输出共享24维、补充24维、待抑制16维，没有分解之后的独立共享速度场。

第二次循环再次输入原始64维表示，并复用同一流的参数。流条件由第一次分解的共享与待抑制坐标、跨模态共享相似度、共享／待抑制相似度、不确定性提示与模态权重生成。训练与推理均执行同样的循环，不使用真实标签作为反馈输入。

## 加入的不确定性

每个共享分支有一个独立高斯预测头，输出单模态标签预测均值μ_m及log-variance l_m：

    q_m(y|S_m)=N(μ_m,exp(l_m))
    l_m=3*tanh(raw_m)，所以方差被限定在exp(-3)至exp(3)

训练损失包含高斯负对数似然：

    NLL=0.5*[log(2π)+l_m+(y-μ_m)^2*exp(-l_m)]

这里预测的是标签空间的异方差，是任务可信度代理；并非直接预测S坐标的概率分布。它也不保证准确区分不可约数据噪声与模型拟合误差。高不确定性不等于冗余，更不意味着该模态必须删除。

可靠性权重：

    w_m=0.1+0.7*softmax_m(-SG(l_m))

三路权重和为1，每路至少0.1。权重停止梯度，方差由NLL训练，避免模型通过放大方差直接逃避对齐损失。

权重参与三个位置：

1. 共享融合：shared_base输入Σ_m w_m S_m。
2. 共享拉近：同一样本跨模态对比项的权重为3*sqrt(w_i*w_j)，减少低可靠性模态对的拉近力度。
3. 流反馈：将三路log-variance及权重追加到关系读取向量，形成132维条件输入。经132→64→32的反馈MLP，更新c_next=0.5c+0.5tanh(B(u))。

S与R反馈输入跨轮停止梯度；关系投影、反馈网络和下一轮条件流仍能由下一轮损失学习。两次分解都受到任务监督。

最终预测仍是shared_base＋补充分支修正。新增最终方差头读取S和C拼接144维，输出最终预测的异方差；R不进入均值或方差预测头。最终方差用于评价预测不确定性，不直接指导同一轮分解。

## 三个对照

| 名称 | 分解次数 | 融合与拉近权重 | 反馈条件 |
| --- | --- | --- | --- |
| direct_uniform | 1 | 均匀 | 零条件 |
| cyclic_uniform | 2 | 均匀 | S/R关系，方差提示置零 |
| cyclic_uncertainty | 2 | 逆方差可靠性 | S/R关系＋方差与权重 |

所有对照都构造并训练相同的高斯头、预测头、流与反馈模块，配对种子初始化完全一致，参数量均为425033。一次分解对照不使用反馈网络；不确定性循环与普通循环的计算结构相同。三者使用同一损失函数，区别是前向路由及循环次数。

本轮联合检验不确定性对融合、对比约束和反馈的影响，尚不能分别归因给其中某一个位置；若效果稳定，再加入weight-only和feedback-only消融。

## 训练目标与选择

每次分解的目标：

    最终均值MSE + 0.2最终Gaussian NLL
    + 0.5共享基础MSE
    + 0.25补充修正MSE(delta,y-SG(base))
    + 0.05三路共享均值MSE + 0.1三路Gaussian NLL
    + 0.02可靠性加权跨模态对比损失(温度0.2)
    + 0.005标准化S-R及C-R跨协方差平方
    + 0.05共享／待抑制坐标标准差下界(0.5)
    + 0.0001全坐标能量

两轮总目标=(末轮损失+0.25首轮损失)/1.25；一次分解用其唯一损失。AdamW学习率5e-4、weight decay1e-3，batch size64，梯度裁剪5。种子0、1、2，每次最多60轮，验证MAE连续12轮不改善则停止；以验证MAE选择每个种子、每个对照的检查点。超参数在本轮开始前固定，没有用测试结果调权。

模型选择之后，用验证集拟合一个最终方差的标量校准系数：mean((y-μ)^2/σ²)。原始与校准指标均报告；校准系数不改变模型预测均值或训练时模态路由。

## 评价

- 情感预测：MAE、正负二分类准确率、Pearson相关。
- 不确定性：Gaussian NLL、90%区间覆盖率及宽度、不确定性与绝对误差的秩相关、保留最低不确定性80%样本的MAE。
- 循环：同一模型第一次和第二次分解的MAE、反馈条件范数。
- 分解：训练拟合／验证选择正则的共享、共享＋补充、共享＋补充＋R、R单独线性探针；分支方差；保留条件下的解析逆误差。
- 压力测试：给标准化冻结的语音／视觉编码向量增加标准差0.5的高斯扰动，观察误差、该模态方差、该模态权重变化。这不是原始麦克风／摄像头噪声测试。
- 三种子集成：平均各模型均值；总方差=平均校准异方差＋模型均值的种子间方差。后者仅为集成分歧代理，不宣称严格贝叶斯后验。用矩匹配高斯区间评价，而非精确高斯混合分位区间。

高覆盖率必须结合区间宽度与NLL理解；若高方差只是普遍放宽区间，而不能排序错误，也不能认为不确定性机制成功。

## 可复现运行

```bash
cd /data/coding/selective_flow
python train_v3_uncertainty.py --stage check
python train_v3_uncertainty.py --stage train --epochs 60 --seeds 0 1 2
python train_v3_uncertainty.py --stage evaluate
```

训练和测试由独立命令执行；训练只读取train/valid。`selection.json`记录源文件、数据、编码器和模型检查点哈希；测试评价核对这些内容。保存验证预测、测试预测、校准系数、逐种子结果和检查点。

此前已查看同一MOSI测试划分的首轮和第二轮结果，因此本轮整体仍是探索性研究，不能当作完全独立的确认实验。三分支含义与不确定性可信度都需要实证检验。

## 方法依据

- Kendall & Gal, [What Uncertainties Do We Need in Bayesian Deep Learning for Computer Vision?](https://arxiv.org/abs/1703.04977)：异方差预测与数据／模型不确定性的区分。
- Lakshminarayanan et al., [Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles](https://arxiv.org/abs/1612.01474)：独立模型集成的预测不确定性。这里仅作三种子结果诊断，未用于训练中的路由。
