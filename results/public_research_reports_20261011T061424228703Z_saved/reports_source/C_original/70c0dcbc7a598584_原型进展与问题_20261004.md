# 任务反馈流原型：实际进展与未解决问题

## 当前结论

新原型已经实现并实际运行。四步流在第二步后读取任务作用观测，反馈改变后两步的速度与状态；前向不接收标签。来源隔离、padding和梯度检查通过。

但是，任务相关共享、补充、冗余的可验证识别仍未成立。条件增量目前是预测器相关的误差对比，不能直接作为语义分类真值。以下全部新实验属于结构检查、合成学习或已有特征上的新训练内读出检查，没有新增MOSI完整训练或测试。

## 1. 实际实现与检查

- `task_feedback_flow.py`：四步Euler；第二步后反馈；七来源观测；每条路径只读自身子组合；误差估计派生12条条件增量。
- `check_task_feedback_v2.py`：在N节点实际CPU执行，报告实际时间2026-10-04T13:34:01.044942Z，17项检查全部通过。
- 不可用文本对A、V、AV路径的预测与最终状态影响为0；padding预测影响为0。
- 任务反馈相对零反馈改变最终状态，最大差0.000143816。
- 速度场、观测头、反馈映射和解码器均获得主任务梯度；反馈参数解析梯度−6.409135204e−6，有限差分−6.409134334e−6。
- v1检查脚本调用Torch2.1没有的`unravel_index`而失败，失败记录和原源码保留；v2仅换用整数`divmod`并实际通过，模型源码未因此修改。

这些结果确认实现的计算与梯度路径，不确认情感性能、语义识别或方法创新。

## 2. 条件增量目标的代数限制

若比较预测p_S和p_U的平方误差：

    (y−p_S)² − (y−p_U)² = (p_U−p_S)(2y−p_S−p_U)

给定可见状态后的条件期望，也可由普通任务均值预测E[y|状态]派生。增加“增量头”本身不产生独立的关系真值。

`relation_target_lab.py`在三个预先定义的合成情形中实际执行。每个情形用1200条拟合教师、600条拟合关系头、800条评价，三个集合不重叠。在这三个情形中，普通任务预测器派生的增量都优于专门误差头的增量。结论是必须保留普通任务预测反馈对照，不能只和零反馈比较。

合成检查同时确认：

- 单独A或V弱，AV协同仍可能强。例如该情形A/V的MSE约1.09/1.12，AV约0.167。
- 有用的重复可以降低估计噪声。例如两条带噪共同来源组合MSE约0.0267，小于单独来源约0.0436/0.0429。

因此，弱来源不能整体关闭，重复不能直接等于应删除的冗余。

## 3. 实际合成流训练

新合成任务为`y = 0.6T + A×V + 噪声`，用于检验条件协同。教师1200条、学生训练600条、合成验证800条分别生成；教师未见学生标签。所有对照使用同一初始化、400次更新、每批64、相同批序、学习率0.003、相同辅助目标、四步流及相同已分配参数。每50步记录，以完整路线合成验证MSE选择。

| 对照 | 最小合成验证MSE | 对应MAE |
|---|---:|---:|
| 零反馈 | 0.171300 | 0.273675 |
| 普通状态反馈 | 0.164313 | 0.270108 |
| 经过观测网络的普通隐藏状态反馈 | 0.175955 | 0.285512 |
| 任务误差与条件增量反馈 | 0.136025 | 0.250290 |

第三个对照是为检查额外观测网络计算而新增的独立控制。`task_feedback_flow_v2.py`只增加该模式；新增控制前已实际检查原零/状态/任务模式在同一合成批次的所有输出逐位相同，参数初始化相同，来源隔离保持。没有重新训练此前三个对照。

这是单次合成实验中的可训练性证据。它没有证明稳定收益，也没有解决普通任务均值反馈对照的缺口。已分配参数相同不意味着有效容量、输入信息与梯度通路完全相同。

任务反馈选中点的训练关系损失约1.259，高于零反馈约0.751：主任务反馈可能改变观测头对误差目标的拟合。预测改善不能代替独立关系准确性验证。本轮没有为补报指标重复这些训练。

## 4. 已保存真实训练特征上的新可行性检查

`check_frozen_train_targets.py`只读取既有V8七路线seed128的1281条训练特征和标签，未读取dev/test数组，未重新做模型推理或原诊断。

新读出分为321/321/320/319条：两组教师头、关系头、评价。来源特征取已有的前流T/A/V编码块；两组教师各自拟合归一化和ridge，固定alpha=1。

部分加入A/V的作用符号在两组教师头间只有约45%–59%一致。例如T→TA约52.7%，TV→TAV约45.1%，TA→TAV约50.2%。不能直接把这些不稳定目标用于硬选择。

重要局限：原编码器训练时见过全部1281条标签。因此，新的读出头虽有独立拟合行，整个教师并不独立。尤其文本路径训练内MSE约0.038不能作为泛化证据。本检查仅暴露目标构造的风险，不验证V9真实性能。

`teacher_provenance_gate.py`补充检查教师预测头、编码器监督训练、教师选模三处标签暴露，并拒绝不声明编码器标签暴露的记录。该文件目前只做接口契约检查，尚无真实独立教师产物通过；申报信息还须与实际运行和文件SHA审计一致。

## 5. 接下来需要实际解决的工作

1. 构造完整教师独立性：固定未用MOSI标签的表示，或在训练内另行拟合整个教师并使目标行不参与教师训练及选模。只重拟合已监督编码器后的预测头不够。
2. 加入普通任务均值预测反馈对照，排查增量目标与普通预测器的代数等价，以及有效容量差异。
3. 独立评价关系准确性、教师间稳定性和协同保留，再检查反馈是否改善真实训练/验证。先不安装硬压缩或任务guard。
4. 对“共享、补充、干扰”给出可检验的操作定义与失败反例；不把标量分数自动称为三类特征空间。

本轮未冻结正式方法或五种子新队列。原始研究目标仍在推进，已有实验结束与研究目标完成分别记录。
