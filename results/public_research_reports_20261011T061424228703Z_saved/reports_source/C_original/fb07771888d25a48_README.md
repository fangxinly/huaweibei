# 独立音视频训练诊断

第六轮同条件无流融合MAE0.6143优于两个流版本；但音视频辅助头近似常量、等长度置乱影响很小。此处检查随机初始化的音视频编码器是否因低学习率和文本任务竞争而未学好。

音频与视觉分支之间没有共享可训练参数，也没有文本、流或融合。使用第六轮相同74／47维输入、100维投影、三层Transformer、内容mask、固定训练通道统计、有效均值池化与线性头。两档学习率1e-5和3e-4使用相同初始参数、seed128、batch32、100轮、AdamW分组和10%warmup；损失为两路MSE的平均。

train1281／dev229，依据两头的平均验证样本MSE选择一个检查点；两个模态共用选择轮次。**本诊断不评估测试集**。独立音视频任务与第六轮弱辅助监督不同，学习率效果只可在这里的两档设置间比较。不能称作流消融、预训练模型或多模态性能提升。

脚本 `train_av.py`；实时远端 `status.json`；各目录包含100轮历史、最佳参数、验证预测和结果。训练过程中不改代码、不依据测试结果选择学习率。验证分数来自单种子探索，尚需独立确认。
