# 连续向量近端候选v3：已实现原型与待实施依赖

新增独立候选task_gradient_vector_candidate_v3.py，保留v1/v2及已冻结v5研究原件。当前仅完成NumPy数学参考与AST接口检查，没有运行PyTorch前向/反向、采集真实教师、接入模型或启动训练。该原型用于检验连续性取舍，不代表已选定正式结构或超参数。

对供体消息F、无标签预测的接收者任务梯度â，取严格正的λ，定义

Tλ(F,â)=F−max(âᵀF,0)â/(‖â‖²+λ)。

它是下列强凸问题的唯一解：

argmin_z { ‖z−F‖²/2 + max(âᵀz,0)²/(2λ) }。

正点积分支的驻点方程给出上述闭式解，解的残留点积仍为正；非正点积时原消息F已是最优解。与v2硬投影不同，λ表达对估计一阶有害分量的软惩罚。零梯度时保持原消息，变换在梯度趋近零时连续，正交分量保持。固定â下，这是非扩张映射，即改变输入消息的输出距离不超过原距离；该性质不涵盖同时变化的预测梯度，也不保证实际任务风险降低。

若d=âᵀF>0，则残留点积为dλ/(‖â‖²+λ)>0，沿â方向的保留比例为λ/(‖â‖²+λ)。这个比例是代数缩减因子，没有经过真实教师误差校准，不能称为统计置信度。v3放弃精确半空间保证，保留连续性及零梯度固定反馈起点。λ越小，非零梯度下越接近硬投影，但小梯度附近灵敏度可能越高；不能用λ很小宣称同时解决稳定性和残留问题。

模块的relative_norm2必须显式传入，没有默认正式值。三个接收者的尺度按指定TRAIN教师行拟合sₘ²=mean(‖aₘ‖²/d)，再设置λₘ=κd sₘ²，κ为relative_norm2。这个定义使梯度和TRAIN尺度同时乘k时，λ乘k²，近端向量变换保持不变；它不说明原标量对照的risk_scale也自动不变。κ尚未确定，不能用合成检查中的λ=1当任务参数，也不能在DEV上筛选它。正式候选需预注册TRAIN内部尺度/校准方案与预算。

未调用TRAIN尺度设置接口前，模块forward和辅助梯度损失均拒绝执行；这一检查只是拟合流程的状态标志，不能证明调用者真的只用了TRAIN。仍需采集行ID、划分来源及标签隔离的实际审计。λ设置过程检查float32是否仍严格正且有限；近端函数要求每条消息使用标量λ，拒绝意外广播成逐坐标惩罚。AMP未核验，主接口暂要求float32。

匹配三臂为fixed、scalar、soft_projected。三臂实例化相同梯度头、辅助损失和尺度缓冲；末层零初始化。fixed进入.5F，scalar进入sigmoid(−.125âᵀF/.05)F，soft_projected进入.5Tλ。统一上下文映射为.5c_old+.25∑进入消息；零头时三臂上下文相同。完整模型参数量、初始化SHA、100订单和真实运行时间仍未核验。soft_projected的actual_weights=.5只记录外层幅度，不能当作完整向量变换的标量权重；原消息点积、变换后点积、λ和缩减因子另行返回。

预测梯度在任务消息路径中detach，梯度头由独立TRAIN梯度回归监督。对固定â且正点积的分支，真实单通道上下文的消息Jacobian为

.125 [ I − ââᵀ/(‖â‖²+λ) ]。

平行方向特征值为.125λ/(‖â‖²+λ)，正交方向为.125。数学上平行值严格正，但极小比例仍可能在float32消减中丢失，不能保证实际autograd一定非零。分界处与停止梯度条件须另核验；该解析矩阵不是对预测梯度本身也随输入变化时的完整总导数。

实际任务风险仍可能增加。令所有接收者梯度拼接后的真实梯度为a，误差q=a−â；每个接收者将其两个方向的Tλ相加再乘.125，三个接收者的位移拼接得到Δc。正残留的一阶上界记为

B=.125∑ᵢ max(âₘᵀFᵢ,0)λₘ/(‖âₘ‖²+λₘ)。

则âᵀΔc≤B。若路径Hessian范数有界H，保留消息收益满足

g≥−B−‖q‖‖Δc‖−H‖Δc‖²/2。

这是有条件的下界，不能保证g>0。合成反例ℓ(c)=c₁+c₂²、F=(1,2)、â=(1,0)、λ=1输出(.5,2)，风险增加4.5；其坐标是数学例子，不是模块实际缩放后的情感任务输入。

NumPy核验使用256×6×100合成数组，验证闭式解驻点、点积残留恒等式、固定梯度非扩张、正交保持、零头起点相同、尺度等变性及解析消息Jacobian。原阈值反例两侧的消息变化约.00010008，相比v2约1的跳变更小，但只说明这一合成例子的连续性。证据为连续向量近端候选数学与静态核验.json；没有读取TRAIN、DEV或TEST数组。
