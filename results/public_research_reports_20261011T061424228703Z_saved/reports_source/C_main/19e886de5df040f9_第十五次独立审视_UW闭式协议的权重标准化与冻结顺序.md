## 2. 给出无歧义的共同设计矩阵

令FIT头角色有G=9个视频，视频v有n_v行。固定基础权重

`a_i=1/(G*n_v(i))`，理论上`sum_i a_i=1`。

对原数组转float64后的两特征`x_i=(pF_i,delta_i)`，两头共用且只算一次：

`mu_j=sum_i a_i*x_ij`，`s_j²=sum_i a_i*(x_ij-mu_j)²`。

这是**视频等权人口方差（ddof=0）**，不是232行普通mean/std、样本无偏修正，也不是W加权mean/std。`s_j>0`时`z_ij=(x_ij-mu_j)/s_j`；exact s_j²=0时z该列固定0、对应斜率固定0。不得用任意epsilon分母人为恢复特征，不根据相关性删特征。保存共同mu/s、活跃列、基础权重和行/视频顺序SHA；201只用这些FIT值变换，不重新计算。

共同矩阵`X_i=(1,z_i1,z_i2)`，目标`r_i=y_i-pF_i`保持原sentiment单位。h是预测校正量，输出pF+h；不要与旧rho_hat估计p0-y的减法混用。无需另标准化r；若实现内部对r中心化，必须恢复正确截距和单位，不让两臂各自的target尺度改变ridge含义。

“都仅用FIT算统计”仍可能不匹配：若U用a、W用aW算各自标准差，即使原特征相同、系数个数相同，标准化坐标中的.01对应的原空间惩罚不同。应固定共同a统计来隔离训练损失权重这一因素。

## 3. 两个损失的精确定义

由本次原数组定义`W_raw_i=4*delta_i²`（float64）。全局基础分布均值

`c=sum_i a_i*W_raw_i`，`W_norm_i=W_raw_i/c`。

本次保存的`sum a_i delta_i²=.011203831956316919`给出`c=.044815327825267676`；这是汇总值代数核对，不是头拟合结果。

两个训练权重分别为

`q_U_i=a_i`，`q_W_i=a_i*W_norm_i`，两者总和都为1。

不要遗漏基础a直接用W归一到行均值，不要把每视频W单独归一：后者强行令9视频最终质量再次相同，改变了4delta²目标。视频等权指底层分布；W乘上delta²后有效视频质量不同是预定重加权，不是必须修复的不公平。也不要合并FIT+201归一，或在201重新计算c供训练/预测用。

固定theta=(alpha,beta,gamma)，lambda=.01：

`L_U(theta)=sum_i q_U_i*(X_i theta-r_i)² + .01*(beta²+gamma²)`；

`L_W(theta)=sum_i q_W_i*(X_i theta-r_i)² + .01*(beta²+gamma²)`。

截距alpha不惩罚，两个标准化斜率惩罚相同；残差损失与惩罚前均无额外1/2或行数系数。若两项都乘同一个1/2，最优解不变；只乘其中一项会改变实际lambda。

**sum与mean必须按这个定义实现。**已有q总和1后又对232行取mean，会把实际ridge放大232倍；改用和为232的sample_weight再同alpha .01，则会把它相对数据项缩小232倍。两臂“都调用Ridge(.01)”不保证符合这里的协议。直接保存实际q和objective定义最清楚。

训练未正则化结构化Q恒等式仍是

`sum_i a_i*(Q_hat_i-Q_i)² = c*sum_i q_W_i*(h_i-r_i)²`。

所以本协议W等价于`raw Q-MSE + c*.01*(beta²+gamma²)`的优化，而不是`raw Q-MSE + .01*penalty`。归一目标后同lambda的U/W比较是合法固定recipe，须如实描述；不能把全局归一常数在带ridge时声称“无论在哪里都完全抵消”。

## 4. 加权截距、求解与数值核验

推荐直接解明确的3×3系统：

`(X^T diag(q) X + .01*diag(0,1,1)) theta = X^T diag(q) r`。

或用等价增广加权最小二乘，追加`[0,sqrt(.01),0]`和`[0,0,sqrt(.01)]`两行、目标0。两臂同一个求解函数，只替换q；float64，固定算法，避免显式矩阵求逆。sum q>0且两斜率有正ridge时系统有唯一解，包括零方差特征情形；不需要通过新jitter或lambda sweep处理精确共线。

共同z在a下均值0，**在q_W下通常不为0**。因此W截距应满足

`alpha_W=sum_i q_W_i*r_i - beta_W*sum_i q_W_i*z_i1 - gamma_W*sum_i q_W_i*z_i2`。

不能把W截距锁成U的mean(r)、只解两斜率后漏掉均值项。内部为消元而用各自q中心化z和r是可以的，前提是不换共同标准差、正确恢复截距和预测；这与重新定义W特征标准化不同。

只有一个截距：显式1列配自定义diag(0,1,1)，或无1列配正确的unpenalized intercept实现；不能既加1列又让库自动加一个截距，也不能默认把显式1列与斜率一并ridge。

保存theta_U/W、训练objective的数据项/惩罚项、weighted residual均值、系统残差、finite状态和共同变换SHA。截距条件与正常方程核验是数值实现检查，不是新学习臂；不能根据哪个实现分数更高挑solver。失败时记录数值原因并修复等价计算，不静默改lambda、删视频或clip系数。

exact abs(delta)常数的数学规则保留：W_norm恒1，U/W等价。当前分布不符合它。小的浮点归一残差应记录/使用固定权重均值约定，不把“近似恒1”另设容差合并模型；不增设按结果决定的数值科学阈值。

## 5. 哪些差异是W本来要引入的，哪些破坏匹配

| 事项 | 预定允许的差异 | 会破坏当前U/W归因的变化 |
|---|---|---|
| 输入与特征 | 完全同pF/delta、共同mu/s、同X | W专属特征/标准差/截断/额外元数据 |
| 监督 | 同一FIT行r=y-pF | 不同label、遗漏行、符号或参考锚 |
| 基础视频权重 | 同一a | 一臂pooled、另一臂视频等权 |
| W | q_W=a*4delta²/c | 每视频归一、epsilon填充、其它剪权/删行 |
| 目标/正则 | q变化自然改变拟合alpha/beta/gamma | lambda、penalty坐标、截距惩罚、额外mean系数变化 |
| 读出 | 同h规则下的free/interval/discrete | 给某臂专属幅度、阈值、output clipping或挑读出 |
| 评价 | 同视频MSE、同作者五指标合同 | U用a评价、W用aW评价后冒同风险胜负 |
| 数据/推理 | 同唯一best和同候选实现/行序 | 重算一臂pF、不同构造/batch/统计、201调参 |

W截距和预测整体均值不同，是损失权重变化的一部分，不需人为固定成同alpha。主基线常数按共同a的FIT残差均值计算：`k=sum a_i*r_i`，输出pF+k；不把常数按每臂重拟合后仍称同一个基线。W加权残差均值可作为拟合诊断记录，不必为它新增一套方法。

最终比较双方在相同评价分布的真实风险：各策略在201的**同一视频等权MSE/paired Q**，以及同作者口径的pooled Acc7/非零Acc2与weighted F1/全行MAE与Corr。W是训练目标权重，不是让W只在“对自己有利的weighted评价”下胜出。额外加权误差如果报告，必须两臂在同一指定权重下并列，并标诊断而非替代主比较。

## 6. 读出和精度也要共同固定

对每个h计算三个校正：

- free：`d=h`，预测`pF+h`。
- interval：`d=clip(h,min(0,delta),max(0,delta))`，预测`pF+d`。
- discrete：`delta²-2delta*h<0`才接受保存的真实pC，否则pF；相等回F。

delta<0也使用同一公式，不能只看h和delta同号而忽略幅度；不能把interval写成不区分正负的[0,abs(delta)]。delta=0应回F。保存实际pC与delta来源，离散直接选择真实候选数组，不伪造另一个输出空间候选。

头变换/系数/读出统一float64，原FP32 pF/pC只作无修改的float64表示；各方法均同精度。MAE/Corr不新增[-3,3] clipping；clip-round只在Acc7内部，区间投影是方法定义，二者不同。五指标都使用同一最终回归向量，不给某指标另造预测/阈值。F、C、常数、两头三读出共9个预定产物，若有exact重复照实标记，不算多个独立训练算法。

保存两类比较：同读出W对U说明权重recipe差异；同h的interval/discrete对free说明约束读出差异。W-discrete胜U-free不能单独归因W或消息。F、C、常数仍是固定锚点，不因为它们在FIT表现好坏而增删。没有新标签收益时，1/232二分类覆盖不能成为优先选free的后验理由。
