# 外部AI意见评议与后续诊断修订

状态：两份附件已全文阅读；引用的CaReFlow、DVIB及多模态信息论综述链接已打开核验。本文是研究评议和待冻结诊断建议，不是新的GPU结果，不修改既有正式源或计划。独立本地float64反例证据由work/analyze_external_flow_opinions_v1.py生成。

第一份建议是shared/private双分支加选择性对齐的架构假设，可以作为另行匹配的结构对照，但不能把分支名称当成语义已识别。shared/private分解已有文献，例如DVIB通过互信息约束和变分界定义其目标；它不替这里的正交与辅助任务损失证明语义识别。CaReFlow原论文本身也将cycle设计用于减少映射信息损失，不能假定旧方法完全没有信息保留机制。来源：https://arxiv.org/abs/2105.07599 、https://arxiv.org/abs/2602.19140 。综述https://arxiv.org/abs/2609.14421讨论MI/IB/PID的不同角色，不能证明本提案等于PID分解。

第一份方案的主要边界：
- cross-covariance为零只限制二阶相关，不等于统计独立、跨模态共享或互补语义。
- 单独能预测标签不等于对其他模态有条件增量；所有U都复制同一标签相关信号时，辅助任务很好但可能高度冗余。纯联合任务如独立二进制输入的XOR，也不由单模态预测能力定义。
- 存在退化路径：令全部S常量0，U承载可拟合的任务信号，flow/cycle/orth损失可全部很小，任务和辅助头由U完成。现有损失形式没有自动排除这一情况；这是可行反例，并非观察到本数据已塌缩。
- shared aggregation减少拼接维数，不证明消除了任务冗余；modality probe接近随机与t-SNE混合不证明逐样本语义对应。常量S也满足这些表象。
- cycle重建误差小不自动保证全分布可逆或稳定；将流端点改为共同学习的projector输出，会改变目标训练路径，不能只按替换张量名称解释为原方法原封不动。

第二份意见与当前有限风险机制相符，可采用逐样本方向消息、任务风险引导向量调整、固定模型干预检验的组织方式。论文主张仍是待验证的任务功能性控制，不是已识别共享/互补/冗余真值，也没有性能优势或新颖性优先权证明。

必须修正的数学判断之一：设固定参考p0，δ(z)=p(z)-p0。相同后半段、近端项、beta、TRAIN尺度、约束和标签下，

J_direct(z) = .5||z-F||² + β(p(z)-y)² / s²，

J_residual(z) = .5||z-F||² + β[2(p0-y)δ(z)+δ(z)²] / s²。

二者之差为β(p0-y)²/s²，与z无关。梯度、Hessian及精确最优解相同。因而“真实风险oracle”不比“真实残差oracle”更强；两实现可用作数值/梯度一致性核验，不能当三个不同能力层级。当前实际控制使用有限3步与信赖域，应报告所得可行结果，不使用argmin符号暗示求得全局最优，不将有限步oracle称严格上界。

必须修正的数学判断之二：代理下降100%、逐样本观测损失下降约50%不能单独证明条件残差估计失准。令Y为等概率-1与+1，μ=0，p0=.1，完美教师给ρhat=.1，取δ=-.1。所有输入的代理条件风险下降.01；两个标签上的观测损失变化为-.21和+.19，实际改善率恰为50%，期望风险仍下降.01。条件均值教师无法预知不可约标签噪声。当前C2不胜匹配对照及残差/效用诊断支持继续排查教师、可达空间和优化路径，但不能唯一归因教师。

建议追加而未实施的最小诊断：先冻结现有C2权重、原消息F、参考p0、原TRAIN尺度/beta/3步/信赖域，比较同一权重的raw固定消息、已学习残差控制、真实标签残差oracle，以及零残差/标签错配负控制。oracle只在TRAIN诊断先行；不接触TEST，不用DEV oracle选择结构或超参。真实风险直接式仅与oracle展开式校验前向/梯度/HVP和轨迹对应，不重复计算当作更强算法。

如果需要严格的逐例不劣性质，先把原F纳入候选，并按同一真实oracle目标保留最佳可行候选：近端项非负且在F为0，故J(z)<=J(F)可推出该样本真实平方损失不高于F。这是标签已知条件下的诊断性质，不是无标签推断泛化保证。没有改进也只能说明此权重、约束与求解预算未找到改进，不能证明所有消息参数化均无效。

预先保存诊断量：观察残差MAE/MSE、符号及均衡指标、原标签残差分布；代理与观察风险的Pearson/Spearman/符号和均值；逐消息变化范数/夹角、输出可达变化δ、逐步目标、最佳候选与边界命中；逐视频样本加权和视频等权口径。残差符号与风险改变符号不是同一个指标；相关性不替代校准，oracle逐例改善也不证明无标签方法可实现收益。

建议研究顺序：先在合法GPU访问与保存预算恢复后执行短的固定权重TRAIN oracle诊断，确认当前可行消息空间及求解器有无改善余量；再结合教师独立误差证据决定是否开展已准备的视频外折教师。oracle成功只提供受约束的标签已知改善证据；教师隔离实验仍未部署/启动，既有A参考仍全TRAINfit/DEVselected，不称全流程crossfit。九个完成模型、旧缺口和租期保存边界均保留。
