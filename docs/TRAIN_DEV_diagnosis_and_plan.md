源码可证实：旧流对最终预测做主MSE，并加入FM、cycle、受监督单模态和variance项；没有直接监督流前融合后的预测。不能说它完全没有监督辅助项。由此提出的机制假设是，流变换及辅助目标可能没有保持融合表示对情绪强度、近零符号的可用性；现有保存数组不能证明这一因果关系。

下一方法已固定为一项候选：

1. 直接监督流前融合预测p_base，使融合表示本身承担情绪预测任务。
2. 输出p=p_base+tanh(gain)*(p_flow−p_base)，gain从0开始。初态输出严格等于流前预测；训练后不承诺不劣于流前，也不声称风险界。
3. 固定损失：finalMSE +0.25*finalMAE +0.5*sourceMSE +0.1*非零符号softplus。移除旧FM/cycle/单模态/variance目标。不按已评分TEST调系数或读出。
4. AdamW主学习率1e−5、单个gain学习率1e−3，10%warmup，梯度clip1，固定seed128；全部模型参数参与训练。公共编码器重新初始化，不继承旧任务或预检权重。
